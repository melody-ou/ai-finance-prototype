Data Upload

Follow the three steps from left to right: identify the accounts first, load phased Budgets next, and then load Actual journal lines. Data remains only in this browser session.

No pre-loaded data
  • Required order: Master Chart first so account numbers and names can be identified; Budget Detail second so every analytical stream exists; Actual Transaction Detail last so journal lines can be matched and validated.
  • Select multiple Budget or Actual CSV files together. Each file is validated separately: passing files are checked for loading by default and receive condensed source previews; failed files remain isolated with a condensed error preview and DELETE action.
  • The current reporting year is the latest year with both Actual and Budget data. Its reporting month is inferred from the latest posted Actual period.
  • At least three completed historical years improve Reforecast support; current-year calculations still work without them. Refreshing or closing the page clears all uploaded data.
